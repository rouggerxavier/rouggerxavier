## 👋 Sobre mim

Sou estudante de **Ciência de Dados e Inteligência Artificial na UFPB**, com foco em construir produtos que unem **IA aplicada**, **engenharia de software**, **automação**, **backend** e **interfaces modernas**.

Meu trabalho hoje é transformar modelos, agentes e pipelines inteligentes em sistemas reais: produtos com API, autenticação, persistência, avaliação, deploy, experiência de usuário e integração com fluxos de negócio.

```txt
AI Engineering        RAG • agentes • grounding • avaliação • fine-tuning
Backend & APIs        FastAPI • Node.js • JWT • integrações • pipelines
Frontend              React • TypeScript • Vite • Next.js • Tailwind
Cloud & Deploy        Docker • Vercel • Render • Fly.io • Google Cloud
Data & MLOps          Vertex AI • datasets • evals • CI/CD • automação
```
